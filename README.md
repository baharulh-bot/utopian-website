## 🚀 How to Run & Preview

### Option 1: Direct File Opening (No server needed)
Double-click `index.html` in your file explorer, or right-click and choose **Open with Google Chrome** (or Edge/Firefox).

### Option 2: Local Web Server via Python
In this folder, open PowerShell or Terminal and run:
```bash
python -m http.server 8000
```
Then visit: [http://localhost:8000](http://localhost:8000)
